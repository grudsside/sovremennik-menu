# Control v3 regression hotfix · 30.07.2026

Исправляет три регрессии после перехода на Control v3:

1. вкладка «Ревизии» не должна оставаться на бесконечной загрузке и сохраняет последнюю доступную копию данных во время обновления;
2. фильтр «Официанты» и раскрытие отчётов работают через прямой обработчик событий;
3. одинаковый чек-лист нельзя отправить повторно после успешной отправки или постановки в офлайн-очередь; оба независимых хранилища черновиков очищаются.

Production не изменяется до прохождения preview и отдельного согласования.
